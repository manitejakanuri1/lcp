# uv dependency overrides, wired up by the UV_OVERRIDE environment variable on the
# Vercel project. Vercel installs the Python function with uv, which ignores pip's
# PIP_NO_DEPS and did not pick up override-dependencies from uv.toml.
#
# rapidocr requires "opencv_python", the desktop build. That wheel installs over the
# same cv2/ directory as the headless one pinned in requirements.txt, and whichever
# lands last wins. When the desktop build wins, cv2 fails to import on the runtime
# with "libxcb.so.1: cannot open shared object file".
#
# The marker is never true, so the desktop dependency resolves to nothing and
# opencv-python-headless ends up the only cv2 installed.
opencv-python ; sys_platform == 'never'
opencv-contrib-python ; sys_platform == 'never'
