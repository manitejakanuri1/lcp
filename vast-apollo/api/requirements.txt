# Offline bill extraction for extract_bill.py. No API keys, no network at runtime —
# the ONNX models are committed under api/ocr_models/.
#
# This list is complete and pinned by hand, and PIP_NO_DEPS=1 is set on the Vercel
# project so pip installs exactly these and nothing else. (pip rejects a bare
# --no-deps line inside a requirements file, so the env var is the only way to get
# the same effect through Vercel's install step.)
#
# Two size constraints shaped this, against Vercel's 500MB function limit:
#
#   - The headless OpenCV build is required. rapidocr declares the desktop build,
#     which needs libGL.so.1 — absent on the serverless runtime, so cv2 fails to
#     import there. Left to resolve, pip also installs the desktop wheels alongside
#     the headless ones rather than instead of them, and each carries its own ~80MB
#     of .so files.
#
#     Pinned to 4.x, not the current 5.0.0.93: the 5.x headless wheel still links
#     libxcb.so.1, which the runtime does not have, and cv2 fails to import with
#     "libxcb.so.1: cannot open shared object file". 4.x is genuinely headless.
#
#   - Base OpenCV, not contrib. img2table would handle the table detection but calls
#     cv2.ximgproc, which only ships in contrib — ~160MB larger on Linux and enough
#     to blow the limit. extract_bill.py rebuilds the table from OCR box coordinates
#     instead, which needs nothing beyond base OpenCV.
