# This list is complete and pinned by hand, and the PIP_NO_DEPS=1 environment
# variable is set on the Vercel project so pip installs exactly these and nothing

# var is the only way to get the same effect through Vercel's install step.)

# Left to resolve, pip installs FOUR OpenCV wheels: rapidocr asks for opencv-python,
# img2table asks for opencv-contrib-python, and the headless builds arrive alongside

# the function to 701MB against Vercel's 500MB limit.
#
# opencv-contrib-python-headless alone satisfies everything: contrib is a superset
# of the base package, and headless drops the GUI libs that need libGL.so.1 —
# absent on the serverless runtime, so the desktop builds fail to import there.
